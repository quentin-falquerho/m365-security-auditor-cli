# M365 Security Auditor CLI 🛡️

`m365-security-auditor-cli` is a lightweight, Python-based Command Line Interface (CLI) tool designed for Cloud Security Engineers and Administrators to quickly audit the security posture and compliance baseline of a Microsoft 365 tenant.

---

## 🚀 Features

- **Automated Baseline Checks:** Scans critical M365 perimeters (Identity, Access, Data Governance, Threat Protection, and Auditing).
- **Rich Terminal Output:** Clean, color-coded tabular reporting directly in your CLI using [Rich](https://github.com/Textualize/rich).
- **Actionable Insights:** Highlights misconfigurations and security gaps (e.g., excessive Global Admins, unrestrictive external sharing).
- **Compliance Alignment:** Helps prepare for security baselines aligned with frameworks like NIS2, ISO 27001, and CIS benchmarks.

---
